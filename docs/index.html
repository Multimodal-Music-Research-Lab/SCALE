SCALE

Structural Context from Audio and Lyric Evidence for Music Structure Analysis.

SCALE detects musical section boundaries and classifies each section as intro, verse, chorus, bridge, instrumental, outro, or silence. This page provides synchronized playback for selected SongFormBench-HX test songs and compares SCALE predictions with the ground-truth annotations on a shared timeline.
